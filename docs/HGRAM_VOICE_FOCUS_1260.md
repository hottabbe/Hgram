# Hgram 13.0.2 (1260): голос и склеенные сообщения

## Склеенные сообщения

Склеенный пузырь подбирает ширину по самым длинным видимым строкам текста,
а не растягивается на весь экран. Текст рисуется обычным размером сообщения;
отдельно снизу — компактная подпись «N сообщений · развернуть» приглушённым цветом
времени сообщения. На исходящие распространяется цвет исходящего пузыря.
Тап и раскрытие исходных сообщений сохраняются.

## Улучшение шумоподавления

Для Ultra и Studio добавлен мягкий гейт *после* нейросети, *до* выравнивания
громкости: остаток фонового шума в паузах не поднимается автоуровнем.
Перед нейросетью установлен HPF 80 Гц с непрерывным состоянием между чанками.
На остановке голосового потоковый denoiser получает flush, хвост записывается
до закрытия Opus. На паузе и отмене native encoder тоже освобождается после
обработки уже поставленных в очередь фреймов. Размер системного AudioRecord-буфера
увеличен для нейросетевых профилей. На кружках PTS строится от начального
аппаратного timestamp и числа считанных сэмплов с компенсацией frame-shift;
это убирает влияние времени исполнения инференса на видеосинхронизацию.

## Фокус на моём голосе — отдельный профиль

Пользователь явно записывает 3 секунды своего голоса при разрешённом микрофоне.
Образец — локальный PCM WAV 16 кГц во внутренней папке приложения; из настроек
его можно заменить или удалить. Он **не загружается на сервер**.

При выборе Focus скачиваются 2 ONNX-модели из официального релиза VoxLock
(`voxlock_enroll.onnx` и `voxlock_chunk_int8.onnx`, всего около 79 МБ). На загрузке
показывается прогресс; оба файла проверяются по SHA-256 опубликованным хешам.

ГС в Focus сначала записывается целиком. После завершения запись декодируется
небольшими чанками из Ogg/Opus в 48 кГц mono PCM16 и обрабатывается VoxLock
с записанным sample; нейросеть внутри сама работает на 16 кГц. Результат
адаптируется обратно к 48 кГц, выравнивается по числу исходных сэмплов и
кодируется в отдельный Opus-файл (64 кбит/с). Только после этого формируются
waveform и запрос отправки. Это выполняется в очереди кодирования, а не в
потоке чтения AudioRecord или на главном потоке. Если очистка не удалась,
исходный файл сохраняется черновиком и **не отправляется автоматически**.

**Граница:** для видеокружка Focus использует RNNoise в реальном времени;
добавить VoxLock для кружка можно только после безопасной пересборки аудиодорожки
уже созданного видео, которой пока нет. Наличие трёхсекундного образца повышает
шансы отделить *свой* голос от другого говорящего, но модель не может обеспечить
идеальное отсутствие всех шумов/чужих голосов на каждой записи.

В VoxLock нельзя подставлять случайный 3-секундный семпл: запись образца должна
быть достаточно громкой и узнаваемой. При отказе в RECORD_AUDIO приложение
попросит разрешение и предложит повторить запись.
