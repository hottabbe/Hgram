# Альбомы — 13.0.2 (1286)

## Изменения

- Footer-ячейки снова проходят штатную отрисовку Telegram: координаты подписи, реакций и комментариев обновляются вместе с hit-test, без сдвигов canvas.
- Высота скрытого медиа исключена из footer. Нижний блок измеряется по подписи, реакциям, времени и комментариям; без подписи и реакций оставлена строка времени.
- Пузырь ограничен нижним блоком. Стопка медиа остаётся сверху.
- Карточки центрированы, задние размыты, шаг каскада 4 dp. Верхняя уменьшается и размывается, следующая увеличивается и проявляется без вылета вбок.
- Только номер сборки повышен; версия 13.0.2, release без R8.

## Проверки

Сборка 1285: assembleRelease успешен, APK переустановлен через adb install -r (с сохранением аккаунта), приложение перезапущено. В канале «в моменте» проверены альбом с подписью и без неё, выравнивание реакций, открытие комментариев и свайп 1/8 → 2/8. Нижние ячейки: 358 и 288 px соответственно при плотности эмулятора 420 dpi.
Итоговая 1286: повторная упаковка после сбоя packageRelease успешна; apksigner verify и adb install -r успешны. После перезапуска повторно проверены «в моменте», подпись/реакции/метаданные, открытие комментариев и перелистывание 1/8 → 2/8; сохранены кадры в покое и во время перехода. Карточки не вылетают вбок, нижний блок сохраняет геометрию. Сценарий полностью пустого footer (без подписи и реакций) предусмотрен кодом, но отдельный такой пост в этой проверке не найден.
