# Проверка Hgram на эмуляторе — 7 ноября 2026

## Условия

Эмулятор Android API 37 x86_64 с ARM-трансляцией, APK `arm64-v8a`. Android Studio, Gradle и эмулятор работали на одном компьютере, поэтому цифры не являются измерением производительности реального телефона. Аккаунт пользователя сохранён; сообщения не отправлялись.

## Проверено

- Авторизация пользователем, переходы из списка чатов в Settings → N-Config → настройки Hgram.
- Открытие диалога голосовых профилей, подтверждение загрузки модели, переключатель объединения коротких сообщений с восстановлением исходного значения.
- Загрузка модели sherpa: при уходе со страницы и возврате показан текущий прогресс; повторное нажатие во время загрузки не запускает новую. Архив скачался и распаковался, статус изменился на Installed, удаление модели через UI восстановило статус Not installed. Фактический архив — 284 МиБ; исправлена оценка в диалоге с 70 до 300 МБ.
- Проверен отказ в доступе к микрофону из выбора Voice Focus; разрешение возвращено в исходное состояние, запись не производилась.
- `simpleperf` при прокрутке и фоновой загрузке записал 7678 выборок без потерь. Повторная запись после загрузки содержит 6445 выборок без потерь. В обоих профилях существенную долю занимают системный ввод-вывод и Android Runtime; при включённой ARM-трансляции и активном Lint определить по ним конкретное UI-узкое место нельзя.
- При четырёх циклах прокрутки настроек до изменений `gfxinfo` показал 3 просроченных кадра из 204, после — 4 из 205. Условия не контролируют всю нагрузку системы; эти данные не доказывают улучшения или ухудшения FPS.
- Автономные микротесты: подсчёт коротких слов и сравнение семантических отпечатков проверены на эквивалентность предыдущему алгоритму; временные затраты отдельных операций снизились. Это не измерение частоты кадров.
- Полный Gradle `testDebugUnitTest`: 74 теста, 0 ошибок, 0 пропусков. Переход из парольного ввода к форматированному тексту воспроизводит ошибку обычного `EditText` в Robolectric; соответствующие проверки разделены, и комплексный переход на Android остаётся отдельным сценарием.

## Ограничения

Микрофон и реальные звонки не проверялись. Просмотрены только выбранные UI-сценарии; не проверены все экраны, комбинации настроек и устройства.
